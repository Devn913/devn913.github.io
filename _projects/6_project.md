A real-time **music-reactive LED matrix visualizer** running on an ESP32 microcontroller — the 8x8 LED matrix responds to audio frequencies creating dynamic visual patterns synchronized to music.

## Features

- Real-time audio frequency analysis via ESP32
- 8x8 WS2812B LED matrix with brightness control
- Multiple visualization modes (spectrum, pulse, wave)
- Python companion script for audio input processing
- Low-latency response (~10ms)

## Tech Stack

`C++` · `ESP32` · `Python` · `Arduino Framework` · `FFT`
