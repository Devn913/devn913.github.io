A web-based bioinformatics toolbox for **protein sequence analysis**, making common sequence analysis tasks accessible through a clean browser interface.

## Features

- **Amino acid classifier** — categorizes residues by physicochemical properties
- **Hydropathy plot** — Kyte-Doolittle hydropathy visualization for peptides
- **FASTA format** support for sequence input and parsing
- **BLAST format** output compatibility
- Interactive visualization using Matplotlib

## Tech Stack

`Python` · `BioPython` · `Django` · `Matplotlib` · `FASTA/BLAST`
