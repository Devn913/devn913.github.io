An open-source **URL shortener** built with Django, featuring a clean Tailwind CSS frontend and SQLite3 database.

## Features

- Short link generation with custom aliases
- Click tracking and analytics
- Clean, responsive Tailwind CSS UI
- SQLite3 backend — zero-config deployment

## Tech Stack

`Python` · `Django` · `Tailwind CSS` · `SQLite3`
