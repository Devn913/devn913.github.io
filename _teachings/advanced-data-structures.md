## Course Overview

Advanced Data Structures was a 6-month course delivered to 2nd year engineering students at ADYPU (July - December 2025). The course covered:

- Time and space complexity analysis
- Binary Trees
- Binary Search Trees
- Dynamic Programming
- Greedy Algorithms
- Graphs
